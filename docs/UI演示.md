# UI 演示

启动：`npm run dev`。构建：`npm run build`。检查：`npm run lint`、`npm test`。

打开首页后，点击「进入演示后台」。登录页已填入示例信息，任何非空输入都只进入演示，不会校验或发送密码。演示登录标记保存在当前标签页的 sessionStorage 中；退出会清除标记。这不是实际身份认证。

## 可以体验

- 激活码：按状态筛选、搜索、生成 1–20 个示例码、复制。演示限制不是正式业务规则。新增数据在页面导航时保留，刷新后重置。
- 教师：搜索、按激活状态筛选、跳转对应教师的 API 用量。
- 课程、评估、字典：选择或拖入文件，也可使用示例材料；体验模拟传输、处理中、成功或结构化错误反馈。
- API 用量：按教师、服务类型筛选，展示不同计量单位和空状态。
- 小屏设备：通过顶部菜单打开导航，宽表格可横向滚动。

## 接口接入边界

`src/demo/data.ts` 集中保存示例数据与 UI 展示类型，不代表服务端接口契约。业务 API 文件暂保持原状；后续明确契约后，所有请求仍统一经过 `src/api/client.ts`。

当前没有实际 HTTP 请求，没有文件读取、解析、上传或内容持久化。ZIP / JSON、50 MB 是演示用基础校验选项；上传进度与结果由本地定时器模拟。不能用于真实账号认证、激活或资源导入。

课程、评估和字典复用 `Content` 页面与 `FileUpload` 组件；实际服务接入时需替换演示计时、结果选择和示例数据，并按照后端返回的信息展示错误，不在前端加入业务解析逻辑。
